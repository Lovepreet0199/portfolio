# Lovepreet Sandhu Portfolio

React portfolio created for HTTP5222 Assignment 2.

## Live Website

https://lovesandhu.com

## Backend API

https://admin.lovesandhu.com

## Technologies

- React
- Vite
- JavaScript
- Bootstrap
- Motion for React
- CSS
- Express API
- MongoDB

## Features

- Dynamic projects from backend API
- Dynamic skills
- Dynamic certifications
- Dynamic portfolio statistics
- Contact form
- Guestbook
- Responsive design
- Animated portfolio interface

## Run Locally

npm install
npm run dev

Create a `.env` file:

VITE_API_URL=https://admin.lovesandhu.com
